# Chaining-RPG

An independent, top-down RPG currently in active development. 

## About the Game
Chaining-RPG features a turn-based combat system built around a chaining mechanic. Players must chain their abilities together within precise frame windows to build up a damage multiplier.
The game features a robust character progression system with unique skill paths.

## Current Development Status & Roadmap
* **Engine/Framework:** C++ & SFML (Custom Architecture)
* **Status:** Active Solo Development
* **Current Milestone:** Optimization and Asset Management. As a solo developer, I am currently navigating scoping challenges regarding the class system.
* I am considering moving to a larger character roster with no class system to make the animation load more manageable for a solo developer.
